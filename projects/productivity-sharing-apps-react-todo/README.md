# React Todo App

## Description
This is a simple React Todo application that helps you manage your daily tasks efficiently. It allows you to add, remove, and mark tasks as completed.

## Installation
1. Clone the repository:

   git clone <repository-url>

2. Navigate to the project directory:

   cd react-todo

3. Install the dependencies:

   npm install

4. Start the development server:

   npm start

## Features
- Add new tasks by typing in the input field and pressing enter.
- Mark tasks as completed by clicking on them.
- Remove tasks by clicking the delete button next to each task.
