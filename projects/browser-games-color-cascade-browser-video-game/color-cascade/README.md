# Color Cascade

Color Cascade is a fast-paced, color-matching puzzle game designed for web browsers. It challenges players' reflexes and strategic thinking as they aim to achieve the highest score possible within a 60-second time limit.

## Game Features
- **Interactive Gameplay:** Click on color blocks to remove matching neighbors and score points.
- **Dynamic Grid:** A 5x5 grid of colorful blocks that refreshes with each match.
- **Score Tracking:** Keep track of your score as you play.
- **Timer:** A 60-second countdown to challenge your speed and strategy.

## Technologies Used
- **HTML5** for structuring the game layout.
- **CSS3** for responsive and modern styling.
- **JavaScript** for game logic and interactivity.

## How to Play
1. Open the `index.html` file in a web browser.
2. Click the "Start Game" button to begin.
3. Click on color blocks to remove them along with matching neighbors.
4. Try to score as many points as possible before the timer runs out.
5. The game ends when the timer reaches zero, displaying your final score.

## Development Setup
1. Clone the repository to your local machine.
2. Open `index.html` in your preferred web browser.
3. Enjoy the game!
