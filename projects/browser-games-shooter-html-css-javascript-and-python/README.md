# Action Shooter

Action Shooter ist ein einfaches 2D-Shooter-Spiel, das mit HTML, CSS und JavaScript erstellt wurde. Das Ziel des Spiels ist es, so viele Gegner wie möglich abzuschießen und dabei Punkte zu sammeln.

## Features

- Steuerung des Spielers mit den Pfeiltasten
- Schießen von Kugeln mit der Leertaste
- Zufällige Generierung von Gegnern
- Punktesystem

## Installation

1. Klone das Repository oder lade die Dateien herunter.
2. Öffne die Datei `index.html` in einem Webbrowser.

## Steuerung

- **Pfeiltasten**: Bewege den Spieler nach links, rechts, oben oder unten.
- **Leertaste**: Schieße eine Kugel ab.

## Spielregeln

- Bewege den Spieler, um den Gegnern auszuweichen.
- Schieße auf die Gegner, um Punkte zu sammeln.
- Das Spiel endet, wenn ein Gegner den unteren Rand des Bildschirms erreicht.

## Anpassungen

Du kannst das Spiel anpassen, indem du die folgenden Dateien bearbeitest:

- **`styles.css`**: Ändere das Aussehen des Spiels.
- **`game.js`**: Passe die Spielmechanik an, z.B. die Geschwindigkeit der Gegner oder die Größe des Spielers.
