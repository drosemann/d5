# Tank Blaster 🎮🚀

## Game Description
Tank Blaster is an exciting browser-based tank shooter game where you defend against incoming enemy tanks. Your objective is to survive as long as possible and score the highest points by destroying enemy tanks.

## Game Mechanics
- **Movement**: Use Left and Right Arrow Keys to move your tank
- **Shooting**: Press Spacebar to shoot bullets
- **Objective**: Destroy enemy tanks and avoid being hit
- **Lives**: Start with 3 lives
- **Scoring**: 10 points per enemy tank destroyed

## How to Play
1. Open `index.html` in your web browser
2. Use Arrow Keys to move left and right
3. Press Spacebar to shoot enemy tanks
4. Avoid letting enemy tanks reach the bottom of the screen
5. Game ends when you lose all 3 lives

## Technical Details
- Built with HTML5 Canvas
- Pure JavaScript implementation
- Responsive game design
