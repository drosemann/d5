📦 INSTALLATION IN 5 MINUTEN
════════════════════════════════════════════════════════════════════════════════

1. BUILD
   $ mvn clean package
   ✓ Erstellt: target/HordePlugin-1.0.0.jar

2. DEPLOY
   $ cp target/HordePlugin-1.0.0.jar /pfad/zum/server/plugins/
   
3. STARTEN
   $ cd /pfad/zum/server
   $ java -Xmx1G -Xms512M -jar paper-1.16.5.jar nogui

4. LADEN
   In-Game: /reload oder /reloadconfig

5. TESTEN
   /horde list              → Alle Horden anzeigen
   /horde start verfluchter-kreuzzug   → Starte Horde

🐛 TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════════

Problem: Horde startet nicht
→ Prüfe: /horde list
→ Überprüfe config.yml auf YAML-Syntaxfehler
→ Schau Server-Log (SEVERE errors)

Problem: Keine Sound-Effekte
→ Prüfe: enable-sounds: true in config.yml
→ Stelle sicher, Spieler ist nicht zu weit weg (>16 Blöcke)

Problem: Mobs spawnen nicht mit Rüstung
→ Das ist normal - equipMobWithArmor() lädt automatisch
→ Prüfe entity.getEquipment() in Logs

Problem: Zu viele Mobs (Server laggt)
→ Reduziere mob-count in config.yml
→ Erhöhe spawn-delay
→ Prüfe Server-CPU: /say done

❓ FAQ
════════════════════════════════════════════════════════════════════════════════

F: Kann ich mehrere Horden gleichzeitig laufen lassen?
A: Nein, nur eine aktive Horde pro Zeitpunkt. Design-Feature.

F: Wie kann ich Custom-Items hinzufügen?
A: Bearbeite LootFactory.java und config.yml

F: Funktioniert das Plugin auf Spigot 1.16?
A: Nur auf Paper. Spigot hat keine optimierten Scheduler.

F: Können Spieler Horden selbst starten?
A: Ja, mit Permission horde.admin

F: Wie lange dauert eine Horde?
A: 10-20 Minuten (zufällig pro Start)
