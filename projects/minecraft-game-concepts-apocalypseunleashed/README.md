# ApocalypseUnleashed

A Minecraft plugin that brings apocalyptic disasters and unique items to your server!

## Features

### Disasters

- **Meteors**: Random falling meteors that create circles of hot meteor, cold meteor, lava, and obsidian blocks. Watch your head!
- **End Of World Meteor**: A massive meteor (spawnable via special jukebox item). Use with caution!
- **Natural Gas**: Deadly green gas cloud that deals rapid damage (spawned by Potion of Gas)
- **Sinkhole**: Random block-destroying voids with lava that can destroy bases instantly
- **Earthquake**: Screen-shaking event that temporarily freezes players
- **Tornado**: Powerful F4 tornadoes that wreak havoc
- **Volcano**: Creates rising formations with player-seeking lava balls
- **Wildfire**: Instant circular fire spread around players
- **Black Hole**: Expanding void that consumes blocks and entities
- **Timephoon**: Chaotic time manipulation affecting game tick rates

### Items

- **Throw TNT**: Instant-kill explosion button (Creative mode: functions as jetpack)
- **Throw Lightning**: Summon lightning with right-click
- **Bred**: Ultimate weapon with 9999 attack damage and infinite uses (rare drop from Knarfy)
- **Coin**: Flippable coin item
- **Apple Of Wisdom**: Blessed by Jchlatt - 50/50 chance of godlike buffs or instant death
- **Golden Apple Giver**: Distributes either Golden Apples or Apples of Wisdom
- **Saturation Filler**: Grants Saturation II effect
- **Mace**: Modern Minecraft mace implementation
- **Music Disc**: Special music disc with bonus secret item

## Installation

1. Download the latest release
2. Place the JAR file in your server's `plugins` folder
3. Restart your server
4. Configure the plugin in `plugins/ApocalypseUnleashed/config.yml`
