# Daniel Rosemann - Personal Portfolio Website

## Overview
This is a modern, responsive personal portfolio website showcasing professional skills, projects, and contact information.

## Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript
- Responsive Design
- FontAwesome Icons
- Google Fonts

## Features
- Smooth scrolling navigation
- Responsive layout
- Animated section reveals
- Contact form with client-side validation
- Interactive project cards
- Gradient hero section

## Setup and Installation
1. Clone the repository
2. Open `index.html` in a modern web browser
3. No additional dependencies required

## Customization
Replace the following placeholders with your personal information:
- Profile image (`profile.jpg`)
- Social media links
- Skills
- Project descriptions
- Contact form backend integration

## Deployment
Recommended platforms:
- GitHub Pages
- Netlify
- Vercel
