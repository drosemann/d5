# Code of Conduct

Be kind and direct. No harassment, hate speech, slurs, or threats. No sexual,
violent, or discriminatory content. Disagree with ideas, not people.

This is a humor project with strong opinions about hosting providers, banks,
and DNS. Jokes punch at systems and situations, never at people or groups.

## Enforcement

Maintainers may edit, hide, or delete contributions that break this code, and
may temporarily or permanently ban contributors after one warning for minor
issues, immediately for serious ones. Report problems by opening a private
GitHub Security Advisory or contacting the maintainer through their GitHub
profile. Reports stay confidential.

## Scope

This code applies in this repo (issues, PRs, discussions, wiki) and in
project spaces elsewhere.
