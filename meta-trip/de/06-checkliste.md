# Checkliste: Vorher, Packen, Vor Ort (DE)

## 4+ Wochen vorher

- [ ] Biometrischer Reisepass, gültig für die ganze Reise
- [ ] ESTA auf esta.cbp.dhs.gov (~40,62 $, mind. 72 Std. vorher)
- [ ] Flüge Deutschland → SFO gebucht (Nebensaison = günstiger)
- [ ] Hotel Menlo Park oder Palo Alto gebucht (Check-in meist 15–16 Uhr)
- [ ] Tag-2-Tour gebucht (alle 5 Stopps in der Beschreibung prüfen)
- [ ] Auslandskrankenversicherung mit USA-Schutz (nicht verhandelbar)
- [ ] eSIM / US-Prepaid-Plan geklärt

## Eine Woche vorher

- [ ] Caltrain- + BART-Apps, Offline-Karten der Bay Area geladen
- [ ] CHM-Öffnungszeiten geprüft (Mo–Di geschlossen)
- [ ] Rückreise-Zeitplanung (Caltrain/Millbrae → SFO)
- [ ] Kamera-/Handyspeicher frei, Powerbank gepackt
- [ ] Bank über USA-Reise informiert (Kartensperren vermeiden)
